# shared/ — 客户端与服务端共享代码（规划中）

> ⚠️ 目录占位。M1 起把以下内容放这里，保证客户端插件与 Cloudflare Worker 引用**同一份**实现：

- `types/` — 牌、牌型、对局状态、WS 协议消息类型
- `config.ts` — 段位阈值、桌别底注、rake、签到额等**可配置数值**（单点修改，双端生效）
- `protocol.ts` — WS 消息封装与版本号
- （规则引擎本体见 [src/engine](../src/README.md)，双端通过构建引入同一源码）

> 为什么共用：避免客户端与服务端对「合法出牌/结算」实现漂移。引擎必须纯函数、无 I/O，才能双端复用。
